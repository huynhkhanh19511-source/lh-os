# Evidence

## Experiment

**Hypothesis:** a demand node can be represented as a structured source of recurring missions rather than as a single job listing.

**Runtime:** `run/main.py`

**Input:** `input/node.json`

**Artifact:** `artifacts/mission.json`

## Current observation

The runtime successfully preserves observed node signals and relationships while producing an explicitly marked `inferred` mission representation.

## What this does NOT prove

- It does not prove mission recurrence.
- It does not prove Vietnam remote eligibility.
- It does not prove that the inferred objective is the node's actual internal mission.
- It does not yet connect the mission to LH's current capability or a deployment outcome.

## Next pressure

Run the same representation against multiple heterogeneous nodes and compare whether the extracted mission schema remains useful. Then connect the output to a capability-gap and runtime-challenge decision.
