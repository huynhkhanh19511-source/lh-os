# Issue Taxonomy

GitHub Issues are part of the execution system, not only a bug tracker.

## Types

- `[MISSION]` — clarify or change system-level mission
- `[FEATURE]` — implement a capability
- `[EXPERIMENT]` — test an idea or hypothesis
- `[HYPOTHESIS]` — make a claim explicit and testable
- `[BUG]` — unexpected behavior requiring correction
- `[OBSERVATION]` — record an important runtime finding
- `[DECISION]` — record an implementation-level decision that needs traceability

## Example

`[EXPERIMENT] Test whether JD signals predict hiring demand`

## Principle

Issues should create an auditable path from reasoning to execution and back to learning.
