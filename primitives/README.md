# LH OS Primitives

Primitives are reusable low-level cognitive or structural operations.

They are not full Skills.

> **Primitive = a basic operation.**
>
> **Skill = a purposeful workflow composed from primitives.**
>
> **Runtime = the environment where Skills meet Reality.**

## Current Primitives

- Extract Primitives
- Map Relationships
- Pattern Recognition
- Structural Analysis

## Architecture

```text
Theory
   ↓
Primitives
   ↓
Skills
   ↓
Runtime
   ↓
Evidence
```

Primitives may be reused across multiple Skills and Runtimes.
