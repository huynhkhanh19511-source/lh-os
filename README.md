# LH OS

LH OS is an executable system for turning knowledge, architecture, and decisions into runtime feedback.

## Mission

Build a system that connects thinking to execution: ideas and decisions are captured, implemented, tested in runtime, and fed back into the architecture.

## System Model

```text
Notion → GitHub → Runtime → Feedback → Notion
```

- **Notion** — memory, knowledge, architecture, decisions
- **GitHub** — execution, artifacts, versioning, experiments
- **Runtime** — reality and observable behavior
- **Feedback** — evidence that updates the system

## Repository Role

This repository is the execution home of LH OS. It should contain executable artifacts, implementation work, experiments, tests, and version history — not act as a duplicate of the knowledge base.

## Current Direction

The immediate goal is to establish the execution layer and close the runtime feedback loop. Projects such as Kinh Architect and Hunter can be developed and validated through this system as they mature.
